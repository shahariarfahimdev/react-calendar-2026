# 2026 Calendar — Shahariar Fahim

React + Vite calendar. The original professor-supplied `date-function.js` is copied byte-for-byte into `public/` and loaded by `index.html`. React calls its `generateMonthData` function.

## Run on Windows PowerShell

Open this folder (the one containing `package.json`) in VS Code, then run:

```powershell
npm.cmd install
npm.cmd run dev
```

Open the **Local** address printed in the terminal (usually http://localhost:5173/). Keep the terminal running.

To stop: Ctrl+C.
